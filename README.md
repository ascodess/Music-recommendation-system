## 📌 Project Overview

This project is an end-to-end Music Recommendation System that leverages Machine Learning to suggest songs with similar characteristics. Using audio and metadata features such as genre, mood, popularity, and tempo, songs are grouped into clusters using the K-Means algorithm.

When a user selects a song, the system identifies its cluster and recommends other songs from the same cluster, creating a personalized listening experience.

The project combines:

* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* K-Means Clustering
* Recommendation Engine
* Flask API Backend
* React Frontend Interface

---

## 🎯 Business Problem

With millions of songs available on streaming platforms, users often struggle to discover music that matches their preferences.

Traditional search methods rely heavily on exact song names or artists. This project addresses the problem by recommending songs based on similarity patterns learned from data, helping users discover relevant music effortlessly.

## ⚙️ Machine Learning Workflow

### 1️⃣ Data Collection

Music dataset containing song attributes and metadata.

### 2️⃣ Data Preprocessing

* Handling missing values
* Feature selection
* Data cleaning
* Normalization

### 3️⃣ Clustering

K-Means clustering groups songs with similar characteristics.

### 4️⃣ Recommendation Engine

When a user selects a song:

* Find its cluster
* Retrieve songs from the same cluster
* Rank and return similar songs

### 5️⃣ User Interface

Recommendations are displayed through an interactive web application.
